# Security Policy

## Supported Versions

| Version | Supported          |
| :------ | :----------------- |
| 0.1.x (Alpha) | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in Compositor, please do **not** open a public issue. We appreciate your efforts to responsibly disclose findings.

### How to Report

Please report security issues privately:
1. Use GitHub Security Advisories: navigate to **Security** -> **Advisories** -> **Report a vulnerability**.
2. Or contact the project maintainers via the email associated with the repository maintainers.

### What to Include
When reporting a vulnerability, please provide:
* A description of the issue and potential impact.
* Steps to reproduce the issue (including any minimal reproduction project or Composable).
* Target platform details (OS, JDK version, Android Gradle Plugin version, Compose version).
* Any possible mitigations or fixes if you have identified them.

### Response Timeline
* **Initial Response**: Within 48 hours acknowledging receipt of your report.
* **Assessment**: Within 7 business days providing an initial assessment and timeline.
* **Patch & Disclosure**: Once resolved, a patched release will be published and an advisory will be issued.
